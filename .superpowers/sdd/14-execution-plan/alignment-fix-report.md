## 5. 우려사항·후속 (사용자 확인 필요)

1. **`CLAUDE.md` 절대 규칙 3에 "확보 시 예상 효과" 문구가 남아 있다.** 에이전트가 `CLAUDE.md`를
   수정하지 않는 정책이라 손대지 않았다 — "가맹 전환 시 예상 효과"로 직접 고쳐야 G-1이 완결된다.
2. **OSRM 공개 데모 서버 값이 감사 실측과 다르다.** 브리프의 감사는 CAND-001을 "포장도로 약
   55km·66분"으로 봤는데 OSRM은 11.0km·50.8분을 준다(임도·비포장 포함 가능성). 결론("직선 6km인데
   차로 50분 이상")은 같지만 **경로·거리 수치를 발표에서 단정하지 말 것**. 필드에는 OSRM 산출을
   그대로 실었고 출처를 05·06에 명시했다.
3. **법인 필터는 상호명 기반 추정이다.** 제외 19건에 `법인백봉`·`법인보보스캇관광농원`처럼 상호
   자체에 "법인"이 든 사례가 있어 오탐 가능성이 있고, 반대로 표기 없는 법인은 걸러지지 않는다.
   코드 주석·11 문서 답변에 한계를 명시했다.
4. **소매점 대표가 `한결퇴비`(퇴비 판매)로 바뀌었다.** 관광 상생 서사와 결이 다르지만 산식 결과라
   그대로 뒀고, 데모 카드는 Score 2위인 음식점(동원각)으로 잡았다. 발표에서 소매점 후보를
   전면에 세우지 않는 편이 안전하다.
5. **FE mock 미동기화.** 이 레포에 `frontend/`가 아직 없어 `scripts/sync-mocks.sh`를 돌리지
   않았다. FE 담당이 `road_distance_km`·`road_minutes`·`proxy_note`를 반영해야 한다(05 계약 변경).
6. **1단계 소비저조도 분모 보정은 하지 않았다**(브리프 지시). §3 보조표가 그 근거 자료다.

## 7. 픽스 라운드 2 (재리뷰 Finding 3 — 고정 시드 ↔ 실시간 생성 구분)

**문제:** 대본(11 §1-2)이 "도로 접근성 역전을 AI가 짚어낸 겁니다"라고 단정하고 `(AI 필요성 ①)`
태그까지 붙였는데, §6에 기록한 실LLM 테스트는 **같은 road 입력에서 모델이 접근성을 쓰지 않고
`adjusted=false`로 Score 1위를 유지**했음을 보여준다. 즉 대본의 핵심 클레임은 사람이 고정한
시드 카드의 내러티브라 "지금 다시 생성해 보여달라"에 재현되지 않는다.

**해결 방향은 은폐가 아니라 구분이다** — "재현성을 위해 고정했다"를 우리가 먼저 말한다.

| 조치 | 내용 |
|---|---|
| 사전 상태 ② 문구 | "AI가 Score 2위→1위로 조정한 상태" → "정량 Score 2위를 1순위로 올린 **조정 사례 예시**. 리허설·심사 리셋 때 서사가 항상 같게 나오도록 **LLM 호출 없이 고정한 JSON**(15 §5 T11)" |
| §1 머리말 | "고정 시드 ↔ 실시간 생성 구분(대본 전체에 일관 적용)" 블록 신설 — 고정 카드를 "AI가 방금 해낸 것"처럼 말하지 않는다고 명시 |
| §1-2 (고정 카드) | `(AI 필요성 ①)` 태그 제거. 접근성 역전은 **"우리 파이프라인이 병기한 도로 접근성 지표에서 나온 사실"**로 서술 |
| §1-2-b (신설, 실시간) | "이번 분기 카드 생성" 버튼(08 문서 F3에 이미 있는 동선)으로 **실시간 생성**을 시연하고 여기에 `(AI 필요성 ①)`를 붙였다 — "Score·추진 상태·계절성·채택/반려 이력을 종합해 조정 후보와 사유를 만들고 원 정량 순위를 항상 병기, **호출마다 결과가 달라질 수 있다**" |
| §1-8 (INCENTIVE) | 같은 문제를 가진 시드 카드라 "이 카드도 시드에 고정한 예시이고 같은 경로로 실시간 생성도 된다(골격은 고정, 비교문·리스크만 LLM)"로 정정 |
| 리허설 합격 기준 | 2-b는 LLM 실호출이라 fallback이 뜰 수 있고, 그 경우 **"지금은 fallback 문구가 나왔습니다"라고 그대로 말한다**(숨기지 않는다)로 명문화 |
| §2 슬라이드 체크리스트 | "Score 2위 → AI 1위" 캡처에 "재현성을 위해 고정한 예시" 표기 + 실시간 생성 캡처를 나란히 두도록 변경 |
| §3 예상 질의 | 2건 추가 — "데모의 조정 사례 카드는 실제 AI가 만든 건가"(아니다 + 실호출에서 조정 없이 1위 유지한 응답도 나왔다는 사실 포함), "카드의 도로 접근성 근거는 AI가 찾아낸 건가"(아니다, 파이프라인 병기 지표). 기존 "정량 1위를 AI가 조정한 사례" 답변도 고정/실시간 구분으로 교체 |
| `seed_demo.py` 카드 B 주석 | "⚠ 이 카드는 LLM이 만든 결과가 아니라 재현성을 위해 사람이 고정한 JSON" + 실호출은 결과가 달라질 수 있다는 실측 사실 + 대본에서 "AI가 방금 해냈다"고 말하지 말 것을 명시. **`ai.reasons` 내용 자체는 유지**(담당자에게 제시되는 근거 예시로 유효) |
