# 01. 개요 — 목표·범위·역할·컷 리스트

## 목표

2박 3일 안에 아래 데모 시나리오가 **배포된 실제 URL에서 30초 안에** 완주되도록 만든다.

> Action Card 허브 진입(상단 "이번 분기 지역 전환율 X%" 헤드라인) → "정량 Score 2위가 1순위로
> 조정된" 사례 카드 확인(재현성을 위해 고정한 예시 — 실시간 생성은 별도 버튼) → 카드 상세에서 1단계(읍)→2단계(500m) 근거 + 지도 확인 → "가맹 전환 시 예상 효과"
> 시뮬레이션 → 승인 클릭 → 상태를 완료로 변경 → 방문객 위젯에 신규 가맹점 우선 노출 확인 →
> 인센티브 정책 카드(페이백 3/5/7% 시나리오 비교) 확인

### 제품 목표

데모 완주 자체가 제품의 최종 목적은 아니다. 지역상생 담당자가 분산된 공공데이터와 개별 문서를
오가며 후보를 찾고 후속 조치를 놓치는 문제를 줄이는 것이 목적이다. 서비스는 **진단 → 후보 비교 →
의사결정 → 실행 추적 → 방문객 노출 → 성과 회고**를 하나의 감사 가능한 Work Item으로 연결한다.

제품이 대신하지 않는 결정도 명확히 한다. AI는 후보를 제안할 수 있지만 가맹 자격·사업자 참여 의향을
확정하거나 정책을 승인하지 않는다. 시뮬레이션은 전망 근거이지 성과 보장이 아니다. 자세한 실사용자
검증 기준과 운영 전환 순서는 [16 문서](16-product-and-production-roadmap.md)를 따른다.

## 역할 분담 (2인)

원안(4인 기준)을 2인으로 재편했다. 바이브 코딩(Claude Max 5x)으로 유탁의 커버 범위를 넓힌다.

| 담당 | 범위 | 산출물 |
|---|---|---|
| **유탁** | 데이터 파이프라인(수집·정제·스코어링·지오코딩), FastAPI+DynamoDB, LLM 연동(카드 생성·시뮬레이션·위젯 문구), AWS 배포 전체, FE 지원(연동 이슈·버그) | `pipeline/`, `backend/`, `infra/`, `data/processed/` |
| **FE 팀원** | Next.js 화면 6종(허브·카드상세·대시보드·인센티브카드·위젯·상태트래킹), mock 연동 → 실 API 전환, 차트·지도 | `frontend/` |

병렬화의 핵심: **FE는 BE를 기다리지 않는다.** `./scripts/sync-mocks.sh`로 `data/processed/` 실산출을
`frontend/src/mocks/`에 채우고 처음부터 화면을 만든다(`05-api-contract.md`의 예시 JSON은 스키마
기준일 뿐 값 원천이 아니다). 유탁이 실 데이터 파이프라인과 BE를 완성하면
`NEXT_PUBLIC_API_BASE` 환경변수 하나로 전환한다. 작업 순서와 게이트는 `10-timeline.md`(Phase 0~6).

## 컷 리스트 (시간 부족 시 이 순서로 제외)

1. **AI 엔티티 매칭 보조** — 원래 optional. 규칙 기반 매칭(반경 500m + 업종 대분류 일치)만 사용
2. **가중치 민감도 분석 자동화** — 파이프라인 스크립트 대신 오프라인 1회 계산으로 슬라이드만 제작
3. **지역별 히트맵** — 표 + 막대 차트로 대체
4. **국세청 지역경제 위험 신호** — AI 입력 ①~⑤만으로 완결 (기획서상 명시된 폴백)
5. **인센티브 카드 시뮬레이션 동적 계산** — 고정 가정치 표로 대체 (승인 플로우는 유지)

**절대 자르지 않는 것:** Action Card 허브 + 승인 플로우 + 지역 전환율 헤드라인 + 카드→위젯 반영 데모.
이 4개가 "시각화가 아니라 의사결정 지원"이라는 포지셔닝의 증거다.

## 성공 기준

- [ ] 배포된 URL에서 데모 시나리오 30초 완주 (리허설 10회)
- [ ] AI 조정 사례 재현 — 시드는 "Score 2위 → 1순위 제안"을 **재현성을 위해 고정한 예시**로 보장하고,
      실시간 생성(`POST /api/cards/generate`)은 별도 동선으로 확인 (결과는 호출마다 달라질 수 있음)
- [ ] 모든 시뮬레이션·전환율 화면에 고지 배지/문구 표시
- [ ] AI 카드의 숫자·순위·상태 문구가 정본 데이터와 일치하고, 후보 적격성 미확인 상태가 분리 표시됨
- [ ] 같은 지역×업종의 활성 Work Item이 중복 생성되지 않음
- [ ] 기준월이 4개월 이상 지난 데이터는 담당자 화면에서 갱신 경고가 보임
- [ ] KPI 4종(채택률·실행 전환율·평균 승인 소요시간·지역 균형지수)이 실제 시스템 상태값으로 계산됨
- [ ] AWS 월 예상 비용 $1 미만(LLM 사용량 제외) 유지
- [ ] **경진대회 제출 요건 충족** (12 문서 §6 체크리스트 전항): Public 저장소 + 심사 요건 갖춘
      README + 시크릿 창·휴대폰에서 배포 URL 정상 실행 + 산출물 정보 문안 제출
