## 5. 차트 팔레트 (검증 완료 — 임의 변경 금지)

업종 6분류(도넛·범례 등 **정체성** 구분)용 카테고리 팔레트. 색각이상 분리(ΔE≥8)·명도 밴드·채도 하한
검증기를 통과한 조합이므로, 색을 바꾸려면 재검증이 필요하다.

| 슬롯 | 업종(고정 순서) | HEX |
|---|---|---|
| 1 | 카페 | `#4f46e5` (브랜드 인디고) |
| 2 | 음식점 | `#eb6834` |
| 3 | 편의점 | `#1baf7a` |
| 4 | 숙박업 | `#eda100` |
| 5 | 소매점 | `#e87ba4` |
| 6 | 기타 | `#008300` |

규칙 (전 차트 공통):

- **색은 항목에 고정** — 필터로 항목 수가 바뀌어도 남은 항목 색을 재배열하지 않는다.
  지역 6종(고한읍→삼척시 고정 순서)에 색이 필요할 때도 같은 팔레트를 같은 순서로.
- 슬롯 3·4·5는 흰 배경 대비가 3:1 미만 → **직접 라벨(값 표기) 또는 표 병행 필수** (목업 도넛처럼
  범례에 %값 병기하면 충족).
- 단일 시리즈 차트(전환율 추이 라인, 지역별 막대)는 팔레트를 쓰지 않고 `admin.primary` 단색.
  크기 비교용 막대에 무지개색 금지.
- **이중 축(dual-axis) 금지.** "리조트 체류 규모 vs 지역 전환 건수" 비교(F5)는 스케일이 다르므로
  나란한 두 차트 또는 로그 없는 단일축 그룹 막대로 — 두 y축을 겹치지 않는다.
- 시뮬레이션 개선폭 순위 바(인센티브 패널)는 크기 인코딩이므로 단색(`admin.primary`) + 순위 라벨.
- 라인 2px, 막대 끝 4px 라운드, 도넛 세그먼트 사이 2px 흰 간격(목업과 동일), 모든 차트에 호버 툴팁.

## 6. 타이포그래피·형태

- 폰트: **Pretendard** (한글 최적, `next/font/local` 또는 CDN). 폴백 `system-ui, sans-serif`
- 숫자 강조(KPI 값): 700 굵기, 크기 단계 28~36px. 단위(%·건·%p)는 값보다 작게·muted
- 카드: 라운드 12~16px, 그림자 `0 1px 3px rgb(0 0 0 / 0.06)` 수준의 은은한 단층
- 배지: 라운드 풀(999px), 12px 텍스트 — `근사 지표`/`가정 기반 전망`/`신규`/등급 칩 공통

## 7. 지도 표현

- **카드 상세의 500m 반경 지도(F4)가 데모 필수 지도**다 — MapLibre GL + OpenFreeMap (02 문서 결정).
- 목업 image-1 히어로의 **6개 지역 폴리곤 지도는 장식성** — 기본 구현은 "지역 칩 그리드"에
  **실존 필드인 `eup_ranking`의 스코어·순위**를 표시하는 형태로 한다. 목업식 지역별 개선폭(%p)
  콜아웃은 `delta_estimate` 계약 반영(§10) 후의 여유 시 확장 (§2-6과 동일 판단). 여유 시 행정경계
  GeoJSON(공개 simplified 소스)을 MapLibre fill 레이어로 얹는다. 시간 부족 시 1순위 컷
  (01 컷 리스트 3번과 동일 취지).
- image-2 위젯의 지도도 MapView 재사용으로 구현 가능하되 **추천 카드 목록이 우선**, 지도는 여유 시.
- 지역별 색칠(단계 구분)이 필요하면 인디고 단일 색상의 밝기 램프(연→진)만 사용. 무지개 금지.

## 10. 05 계약 변경 후보 (FE 시안 확정 시 — 절차: 05 수정 → mock 수정 → 팀 공유 → 코드)
