# 24. 5분 발표 최종안 — 7장 + 60초 데모

## 발표가 해야 할 일

발표가 끝났을 때 강원랜드 담당 심사위원이 다음과 같이 이해하게 한다.

> **상생 나침반은 AI 분석 대시보드가 아니라, 공공데이터를 감사 가능한 지역상생 업무 단위로 바꾸고 완료 결과를 방문객 경험까지 닫는 의사결정 운영체계다.**

이 한 문장이 서비스의 본질이다. 공공데이터·AI·화면 수를 나열하는 대신, 담당자의 실제 업무가 어떻게 달라지는지 증명한다.

## 심사 득점 전략

| 평가 중점 | 발표에서 남길 기억 | 실제 증거 |
|---|---|---|
| **아이디어 독창성** | AI가 답을 대신 내는 것이 아니라, 스스로 반대 관점을 내고 사람의 판단을 더 안전하게 만든다 | 원 정량 순위 병기 · AI 반대 관점 · 승인 안전 검토 · 완료→방문객 폐루프 |
| **기능 구현 완성도** | 안전 원칙이 발표 문구가 아니라 서버 동작으로 강제된다 | 안전 검토 누락 승인 `422` · 순차 상태 전이 · 감사 기록 · fail-closed 인증 · 규칙 기반 폴백 |
| **사회·기업적 활용 가치** | 지역상생 담당자의 분기 업무 루틴으로 바로 발전할 수 있다 | 6종 공공데이터 · Action Card · 추진 트래킹 · 방문객 위젯 · 실운영 로드맵 |

독창성을 서비스 설명과 기능 UI에서 가장 오래 보여 주고, 완성도는 실제 거부·기록 장면으로 증명하며, 활용 가치는 문제 정의·기대효과·사업 가치성에 걸쳐 축적한다.

## 강원랜드 방향과 연결하는 표현

강원랜드의 공개 경영정보는 `상생추구`를 경영방침으로, `윤리·안전`을 핵심가치로 두고 `폐광지역 경제활성화 견인`을 전략방향으로 제시한다. 지속가능경영보고서는 정보보호 관리체계와 개인정보 신규 수집·처리 위탁 시 책임자 사전통제를 설명한다.

따라서 발표에서는 다음처럼 말한다.

> **강원랜드가 공개한 상생·윤리·안전과 정보보호 사전통제 방향을, 상생 나침반의 데이터 처리와 승인 절차 안에 구현했습니다.**

공개 자료에서 강원랜드의 공식 AI 윤리 가이드라인은 확인하지 못했으므로 `강원랜드 공식 AI 가이드라인 준수`라고 말하지 않는다. `서비스 내부 AI 안전 기준을 코드로 강제했다`고 말한다. `편향이 없다`고 단정하지 않고 `편향 가능성을 드러내고 담당자가 통제한다`고 설명한다.

## 1. 오프닝 — 지역상생, 데이터 다음은 결정

### 화면

- 제목: **상생 나침반**
- 부제: **공공데이터를 지역상생의 다음 행동으로**
- 하단 한 줄: `강원랜드 지역상생 의사결정 지원 플랫폼 · TEAM V.I.B.E`
- 배포 URL과 QR은 작게만 두고 마지막에 다시 크게 보여 준다.

타이틀은 최소화한다. 기능명·기술스택·수치를 넣지 않는다.

### 발표 멘트

> 지역상생을 위해 데이터는 이미 공개되고 있습니다. 저희가 해결한 것은 데이터를 보는 일이 아니라, 그다음 결정을 더 안전하게 내리고 끝까지 추적하는 일입니다.

## 2. 문제 정의 + 서비스 목적 — 데이터는 있지만 다음 행동과 성과가 끊겨 있다

### 화면

한 줄의 끊어진 업무 흐름을 보여 준다.

`흩어진 공공데이터 → 현황 보고 ┄ 어느 지역·업종을 먼저 검토? ┄ 승인 후 무엇이 달라졌나?`

오른쪽에는 서비스 목적을 한 문장으로 둔다.

> **담당자의 분기별 지역상생 의사결정을 하나의 감사 가능한 업무 흐름으로 연결**

하단 근거:

- 강원랜드 주요 역할: 폐광지역 경제 활성화
- 경영방침: 상생추구
- 핵심가치: 윤리 · 안전

### 발표 멘트

> 강원랜드에는 폐광지역 경제 활성화라는 분명한 역할이 있습니다. 하지만 데이터는 원천별로 흩어져 있고, 후보 선정은 담당자의 추가 작업에 의존하며, 승인 이후의 추진과 방문객 체감까지 한 흐름으로 남지 않습니다. 상생 나침반의 목적은 이 단절을 분기별 의사결정 업무로 연결하는 것입니다.

## 3. 서비스 설명 — 진단부터 완료까지 하나의 Work Item

### 화면

가장 중요한 독창성 장면이다. 좌→우 폐루프 하나만 크게 그린다.

`공공데이터 6종 → 지역 진단 → 2단계 후보 스코어링 → 서버가 대상 확정 → AI 비교 설명·반대 관점 → 담당자 안전 검토·승인 → 적격성·가맹 심사 → 완료 → 방문객 위젯`

중앙 강조 문구:

> **AI는 설명하고 반박한다. 대상과 수치는 서버가 정하고, 최종 판단은 담당자가 한다.**

폐루프 끝의 화살표는 `승인`이 아니라 `완료`에서 방문객 위젯으로 연결한다.

### 발표 멘트

> 상생 나침반의 독창성은 추천 알고리즘 하나가 아닙니다. 공공데이터로 후보를 찾고, AI가 비교 설명과 반대 관점을 제시하며, 사람이 안전 검토 후 결정하고, 적격성과 가맹 심사를 거쳐 완료된 결과만 방문객 화면에 반영하는 폐루프입니다. 하나의 Action Card가 근거·결정·추진·성과를 끝까지 가지고 갑니다.

## 4. 공공데이터 활용 — 각 데이터에 한 가지 책임

### 화면

6종을 표로 빽빽하게 나열하지 않는다. `진단 → 후보 → 검토 → 활용` 네 단계 아래에 출처를 배치한다.

| 역할 | 데이터셋 | 제공기관 |
|---|---|---|
| 지역 소비 진단 | 하이원포인트 사용현황 · 일자별 카지노 입장객 | 강원랜드 |
| 후보 스코어링 | 하이원포인트 가맹점 상세정보 · 상가(상권)정보 | 강원랜드 · 소상공인시장진흥공단 |
| 중립 배경 검토 | 사업자현황 | 국세청 |
| 방문객 추천 보조 | 초단기실황 | 기상청 |

파이프라인 끝에 보안 장치를 붙인다.

`원천 → 10단계 파이프라인 → k=5 소표본 억제 → 100단위 반올림 → SHA-256 데이터 버전 발행`

하단 출처: `공공데이터포털 · 강원랜드 · 소상공인시장진흥공단 · 국세청 · 기상청`

### 발표 멘트

> 데이터를 많이 모으는 것이 목적은 아닙니다. 하이원포인트는 지역 진단, 상가와 가맹점 정보는 후보 검토, 국세청 자료는 중립적인 배경 확인, 기상 정보는 방문객 추천 보조라는 한 가지 역할만 맡깁니다. 가맹점 5곳 미만 셀은 발행 전에 숨기고 영향 집계는 100단위로 반올림해 개인사업자 역산 정밀도를 낮췄습니다.

## 5. 기능 UI — AI가 판단을 덮지 못하도록 세 번 통제

### 화면

8개 화면을 축소해 나열하지 않는다. 실제 UI 세 장면을 순서대로 보여 준다.

### 장면 A — 근거를 가리지 않는다

- `정량 원 순위 2위 → 선택 가능한 후보 1위`
- 정량 1위가 이미 추진 중이라는 중복 제외 근거
- 원 Score·기준월·출처 상시 병기

### 장면 B — AI가 자기 제안을 반박한다

- 비교 설명과 함께 반대 관점 3개 노출
- 수치·대상은 서버가 재검증
- 성별·연령·국적·장애·종교 등 민감 속성 추론 문장은 폐기
- 실패 시 `규칙 기반 설명`이라고 정직하게 표시

### 장면 C — 안전 확인 없이는 승인되지 않는다

- `결정 안전 검토` UI
- 소표본 보호·원 순위·AI 반대 관점·편향 및 윤리 영향 확인
- 미확인 승인 요청은 실제 API가 `422`로 거부
- 승인 기록에 내부 안전 기준 버전과 확인 범위 저장

하단 미니 흐름:

`담당자 승인 → 적격성 확인 → 가맹 심사 → 완료 → 방문객 위젯`

### 발표 멘트

> AI를 안전하게 쓴다는 말만 하지 않았습니다. 첫째, 서버가 대상과 수치를 확정해 AI가 순위를 덮지 못합니다. 둘째, AI가 이 제안이 틀릴 수 있는 이유를 함께 쓰고 민감 속성 추론 문장은 검증 단계에서 폐기합니다. 셋째, 담당자가 데이터 보호 범위와 편향·윤리 영향을 확인하지 않으면 승인 API 자체가 거부됩니다. 강원랜드가 공개한 정보보호와 사전통제 방향을 서비스 내부 안전 기준으로 구현했습니다.

`편향이 없다`고 말하지 않는다. `편향 가능성을 드러내고 사람의 검토와 감사 기록으로 관리한다`고 말한다.

## 6. 기대효과 — 결정의 사각지대를 줄이고 결과를 측정 가능하게

### 화면

효과를 기능 수가 아니라 담당자·조직·지역의 변화로 보여 준다.

| 담당자 | 조직 | 지역·방문객 |
|---|---|---|
| 후보 비교 시간과 판단 누락 감소 | 결정 근거·보류·반려·상태 이력 축적 | 완료된 확충 업종이 방문객 추천에 노출 |
| 원 순위·반대 관점으로 검토 품질 향상 | 분기별 성과 회고와 정책 학습 가능 | 공급 측 확충과 수요 측 인센티브를 함께 검토 |

하단 실측·전망:

- 현재 진단: 지역 전환율 **20.5%** `근사 지표` · 지역 소비 집중도 **43/100** · 업종별 소비 분산도 **87/100**
- 지역 전환율 1%p 개선 시 연 **+24,787건** 추정
  `가정 기반 전망이며 실제와 다를 수 있음`

### 발표 멘트

> 기대효과는 AI가 더 많은 제안을 만드는 것이 아닙니다. 담당자는 원 순위와 반대 근거를 함께 보고, 조직은 승인·보류·추진·완료의 근거를 축적하며, 완료된 정책은 방문객 화면에서 체감됩니다. 현재 근사 지표 20.5%를 1%포인트 개선하면 연 2만 4,787건이라는 가정 기반 전망이지만, 실제와 다를 수 있음을 함께 밝힙니다.

### 발전 — 성과 기반 지역상생 포트폴리오

- 유사 점수 미실행 지역과 대조군 성과 비교
- 금액 기준 지역 전환 지표 정밀화
- 지역 결제분 한정 사용 리워드 정산 연동
- 다른 지역상생 사업과 관광 동선 정책으로 확장

하단 결론:

> **상생 나침반은 AI가 결정하는 시스템이 아니라, 강원랜드 담당자가 더 나은 결정을 더 빨리 내리고 끝까지 책임 있게 추적하도록 돕는 시스템입니다.**

### 발표 멘트

> 현재는 공개 데이터만으로 전체 의사결정 흐름을 검증한 MVP입니다. 다음 단계에서는 강원랜드의 권한·가맹 심사·정산 체계와 연결하고, 이후 대조군 성과 비교와 금액 기준 지표로 정책 효과를 학습할 수 있습니다. 상생 나침반은 일회성 경진대회 화면이 아니라 분기별 지역상생 운영체계로 발전할 수 있습니다. 지금부터 이 흐름을 실제 화면으로 보여드리겠습니다.

3. 이분할: **“승인이 아니라 적격성과 가맹 심사를 거쳐 완료된 결과만 방문객 추천에 반영됩니다.”**

- 담당자 업무는 인디고, 방문객 경험은 그린으로 구분한다.
- 심사 기준 칩은 오른쪽 위에 작게 두고 슬라이드 제목으로 쓰지 않는다.
- 기능 UI는 [screen-hub.png](../images/screen-hub.png), 안전 검토 승인 화면, [screen-widget.png](../images/screen-widget.png)을 중심으로 구성한다.
- UI 캡처를 8개 나열하지 않는다. `원 순위·반대 관점 → 안전 승인 → 완료·방문객` 세 장면만 크게 보여 준다.
- 데이터 보안·안전한 AI를 별도 선언문으로 떼지 않고, 데이터 발행과 담당자 승인 과정 안에 배치한다.

## 표현 금지와 정직성 규칙

- `Gini`, `HHI`, `지니계수`, `허핀달` 미사용
- 지역 전환율에는 항상 `근사 지표` 표기
- 전망 수치에는 `가정 기반 전망이며 실제와 다를 수 있음` 표기
- AI가 `실행한다·결정한다`고 표현하지 않음
- 가맹점을 `확보`한다고 표현하지 않음
- 페이백을 `추가 적립·추가 지급`이라고 표현하지 않음
- 국세청 신호는 `진단 참고용`으로만 표현
- `편향이 없다`, `강원랜드 공식 AI 가이드라인 준수`라고 단정하지 않음
- 승인 즉시 방문객 위젯에 반영된다고 표현하지 않음 — `가맹 심사를 거쳐 완료된 결과`만 반영
